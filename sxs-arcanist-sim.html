How it works

Turn-based fight of N turns. Each turn the sim casts the ready skill with the best value (damage now + Erosion damage it will add later). Erosion stacks tick each turn and last 3 turns; the detonate skill cashes remaining ticks at once. Crits, Erosion application and gear are sampled with the same random seeds for every build, so comparisons are fair. Search: all skill combos are scored first, the top ones are then crossed with every relic/charm combo, and the winner gets a "what if I remove this" table.

Classes: Sage → Arcanist (Tier 3) → Dominator (Tier 4, unlocks ~Lv 106; one source says "Controller"). If you're already Tier 4, tell me and I'll model Dominator.
